# v1.1.0 配音与画面

v1.1.0 的重点是**配音**和**画面**：每个角色有自己的声音，台词和字幕对得上，音效和配乐不再盖住人声；动态镜头不再卡顿，每个镜头可以有自己的色调和转场，角色一致性多了两道约束。制作页面也相应加了配音表、试听、整集声音样片和逐镜画面查看。

> **尚未通过完整动态出片验收。** 动作提示词加入角色外观、视频复检加入关键帧参照两项改动尚未在真实模型上跑过。本版本代表一套结构稳定、功能完整的短剧流水线，不代表已验收的端到端成片。模型推理默认关闭。

## 这一版有什么

- **按角色选声与配音引擎**：按角色表 `voice`/`voice_rate` → `voice.per_character` → `gender` → 名字/外观推断 → `_default` 顺序选声；长者语速自动乘 0.88；新增 `command` 自定义配音引擎支持（占位符 `{out}` `{voice}` `{rate}` `{text}` `{text_file}`）。
- **配音后处理与长台词切段**：去首尾静音（保留 40ms）、统一 RMS 响度至目标电平、两端 8ms 淡入淡出；超过最大字数的长台词在标点处切段依次显示并平滑淡入淡出。
- **玄幻音效与国风配乐**：支持多音效 `|` 与 `@秒` 定位；新增 `energy`、`fire`、`impact`、`sword`、`thunder`；台词时音效自动压低至 70%；新增 `guofeng` 国风五声音阶配乐（冷色调羽调式、暖色调宫调式），台词前 0.18s 提前以平滑曲线闪避。
- **动态镜头平滑变速与锐化**：短片段相邻帧混合放慢（上限 1.5 倍），超限最后一帧平滑推近（4.5%）；放大比例超过 1.15 倍时增加轻度 USM 锐化。
- **逐镜色调与转场**：每个镜头独立指定 `grade`（`cool` `warm` `golden` `noir` `neutral`）；新增分镜字段 `transition`（`dip` `dissolve` `cut` `flash`）。
- **角色一致性双重约束**：Wan/Animate2 动作提示词注入角色 `anchor` 与外观一致性约束；视频复检抽取 5 帧并前置关键帧基准对比。
- **制作页面交互增强**：分镜预览增加配音表、▶ 试听按钮、整集声音样片卡片（含音频播放、时间轴表格与被拉长高亮、SRT 下载）；任务卡片镜头缩略图支持点击弹窗并排对比关键帧、动作草稿、最终动态镜头与质检意见。
- **开工检查扩展**：配音引擎检查核对分镜实际使用的语音包是否已在系统安装。
- **测试与预览**：新增 `tests/fake_tts.py` 替身程序与 27 项单元测试（总计 74 项）；`tools/preview_page.py` 支持 `--say` 切换真实语音。

## 修复

- 修复转场时使用已烧录字幕的上一帧导致上一镜字幕以半透明残影出现在下一镜开头的幽灵字幕问题。
- 修复分镜示例中 `impact` 音效因缺失合成器静默失效的问题。

